# Source Priority

Use sources in this order unless the user asks otherwise.

1. Authoritative census, atlas, or database page that defines the class
2. High-quality review article
3. Primary paper for ambiguous or disputed members
4. UniProt for accession and protein-name normalization
5. NCBI Gene for cross-checking aliases and organism mapping

Rules:
- Do not use UniProt alone to define pathway or function membership.
- Do not use a single weak abstract to expand a canonical list.
- When sources conflict, keep the stricter interpretation in `Core` and move the rest to `Extended` or `Disputed`.
