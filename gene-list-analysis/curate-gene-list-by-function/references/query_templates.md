# Query Templates

Adapt these templates to the requested category.

## Discovery queries

```text
[category] review [organism] genes proteins
[category] comprehensive review [organism]
[category] census [organism]
[category] domain family review [organism]
```

## Confirmation queries

```text
[gene symbol] [category] PMID
[gene symbol] role in [pathway] PMID
[gene symbol] domain annotation UniProt
[gene symbol] NCBI Gene UniProtKB/Swiss-Prot
```

## Identifier queries

```text
site:uniprot.org/uniprotkb [gene symbol] [organism] UniProt
NCBI Gene [gene symbol] [organism] UniProtKB/Swiss-Prot
[PMCID] PMID
```

## Examples

```text
transcription factors review Homo sapiens gene list
Wnt signaling pathway comprehensive review Homo sapiens
GATA3 transcription factor PMID
SMAD4 role in TGF-beta pathway PMID
site:uniprot.org/uniprotkb TP53 Homo sapiens UniProt
```
